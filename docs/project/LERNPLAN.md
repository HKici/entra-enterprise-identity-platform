# Lernplan

Das Repository dient gleichzeitig als IAM-Lernprojekt.

## Lernmethode

Jede Projektphase folgt demselben Muster:

1. **Konzept verstehen**
2. **Architekturentscheidung treffen**
3. **kleines Lab umsetzen**
4. **automatisieren**
5. **testen**
6. **erklären können**
7. **Erkenntnisse dokumentieren**
