# Naming Convention

Status: **Entwurf**

## Grundsatz

Dokumentation und Business-Bezeichnungen verwenden deutsche Begriffe. Technische Identifikatoren bleiben konsistent englisch.

## Beispiele

### Gruppen

```text
GRP-Warehouse-North-Users
GRP-Warehouse-South-Users
GRP-Store-Users
GRP-External-Contractors
GRP-Privileged-Admins
```

### Conditional Access

```text
CA001-Require-MFA-Workforce
CA002-Require-Strong-Auth-Admins
CA003-Block-Legacy-Authentication
CA004-Protect-Security-Info-Registration
CA005-Require-Compliant-Device-Admins
```

### Administrative Units

```text
AU-Warehouse-North
AU-Warehouse-South
AU-Stores
```

## Noch zu entscheiden

- Präfixe für App-Rollen
- dynamische Gruppen
- Lifecycle-Workflows
- Access Packages
- Enterprise Applications
